# 特性

- **数据库**。支持 SQLite 和 MySQL！
- **同步**。跨多个服务器同步产品数据！
- **模块化**。完全可以禁用您不喜欢的插件部分！
- [**多货币**](https://nightexpressdev.com/excellentshop/features/multi-currency)。在商店商品和拍卖列表中使用不同的货币！
- [**4 种价格类型**](https://nightexpressdev.com/excellentshop/features/price-types)。在虚拟商店和箱子商店中使用不同的价格体系！
- [**购买 GUI**](https://nightexpressdev.com/excellentshop/features/purchase-gui)。简单直观且完全可定制的 GUI 用于购买和出售物品！
- [**虚拟商店**](https://nightexpressdev.com/excellentshop/virtual/overview)。创建完全可定制的管理员 GUI 商店，有许多选项！
  - **游戏内编辑器**。直接在游戏中使用简单直观的 GUI 创建和管理您的商店！
  - [**主要 GUI**](https://nightexpressdev.com/excellentshop/virtual/main-gui)。快速访问商店的完全可定制主商店 GUI！
  - [**库存与限制**](https://nightexpressdev.com/excellentshop/virtual/stocks-limits)。限制在全球及每个玩家基础上可购买和出售的产品数量！
  - [**物品与指令**](https://nightexpressdev.com/excellentshop/virtual/product-types)。支持完整 NBT 的物品、自定义物品插件集成和 PlaceholderAPI 支持的命令销售物品！
  - [**产品要求**](https://nightexpressdev.com/excellentshop/virtual/product-requirements)。为商店商品设置排名和权限要求！
  - [**商店布局**](https://nightexpressdev.com/excellentshop/virtual/shop-layouts)。为您的商店创建完全自定义的 GUI 配置，支持每页布局！
  - [**商店要求**](https://nightexpressdev.com/excellentshop/virtual/shop-requirements)。根据特定条件限制对所有或特定商店的访问！
  - [**商店轮换**](https://nightexpressdev.com/excellentshop/virtual/shop-rotations)。创建随着时间变化的动态商品！
  - [**商店快捷方式**](https://nightexpressdev.com/excellentshop/virtual/shop-shortcuts)。为快速访问商店创建自定义指令！
  - [**出售功能**](https://nightexpressdev.com/excellentshop/virtual/sell-features)。通过 GUI 快速出售整个库存、手中物品或特定物品！
  - [**出售乘数**](https://nightexpressdev.com/excellentshop/virtual/sell-multipliers)。根据玩家的排名或权限提升出售价格！
- [**箱子商店**](https://nightexpressdev.com/excellentshop/chest/overview)。在世界的任何容器方块中创建箱子商店！
  - **游戏内编辑器**。使用简单直观的 GUI 创建和管理您的商店！
  - **全息显示**。使用基于数据包的客户端全息图显示商店信息！
  - **商店银行**。将您的口袋和商店余额分开管理！
  - **商店列表**。通过 GUI 浏览您自己或其他玩家的商店！
  - **商店搜索**。搜索包含特定物品的商店！
  - **商店数量**。根据玩家的排名或权限设置可创建的商店数量！
  - **商店方块**。通过放置特殊商店方块创建商店！
  - **产品数量**。根据玩家的排名或权限设置每个商店可创建的产品数量！
  - **费用**。对玩家创建和移除商店收取费用！
  - [**管理员商店**](https://nightexpressdev.com/excellentshop/chest/admin-shops)。创建管理员商店，拥有无限的库存和资金！
  - [**商店租赁**](https://nightexpressdev.com/excellentshop/chest/shop-renting)。以商店所有者设定的价格和时间租用其他玩家创建的商店！
  - [**商店类型**](https://nightexpressdev.com/excellentshop/chest/shop-types)。设置允许使用的箱子商店方块！包括**信使方盒**、**桶**等！
  - [**领地集成**](https://nightexpressdev.com/excellentshop/chest/claim-integrations)。限制在玩家领地之外创建商店！
  - [**无限存储**](https://nightexpressdev.com/excellentshop/chest/infinite-storage)。绕过方块的库存容量限制，使用虚拟物品存储。
  - **物品黑名单**。防止具有特定名称、描述和类型的物品被添加到商店！
- [**拍卖**](https://nightexpressdev.com/excellentshop/auction/overview)。允许玩家在全球服务器市场上交易物品！
  - **类别**。以完全可定制的物品类别过滤拍卖中的物品！
  - **排序**。按价格、日期、所有者、类型和名称对拍卖物品进行排序！
  - **通知**。为玩家提供关于已售出、过期和未认领列表的通知！
  - **公告**。在拍卖上添加新列表时广播消息！
  - **费用**。对玩家添加拍卖物品收取费用！
  - **容器预览**。在购买前预览信使方盒和箱子的内容！
  - [**列表数量**](https://nightexpressdev.com/excellentshop/auction/listings-amount)。根据玩家的排名或权限设置可以添加到拍卖的列表数量！
  - [**价格限制**](https://nightexpressdev.com/excellentshop/auction/price-limits)。限制某些物品和货币的上架价格！
- **交易日志**。在专用日志文件中记录所有商店交易！
- [**PlaceholderAPI 支持**](https://nightexpressdev.com/excellentshop/hooks/placeholder-api)。

# 兼容性

- **Java 版本**：21 或更高。
- **服务器软件**：Spigot / Paper / Purpur
- **服务器版本**：1.21.4 或更高。

# 依赖关系

**必需：**

- [nightcore](https://nightexpressdev.com/nightcore/) - 插件引擎。
- [EconomyBridge](https://nightexpressdev.com/economy-bridge/) - 经济、货币和自定义物品兼容性。

**可选：**

- [ProtocolLib](https://ci.dmulloy2.net/job/ProtocolLib/) 或 [PacketEvents](https://spigotmc.org/resources/80279/) - 用于箱子商店全息图。
